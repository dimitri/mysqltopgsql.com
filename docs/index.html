pgloader is the open-source tool named in nearly every MySQL-to-PostgreSQL migration guide published — it automates schema translation, data loading, and casting rules in a single command line. This site is written by pgloader's author.

Everything here — the methodology, the FAQ, the course — comes from actually running migrations, not from reading about them. See the project itself at pgloader.io.

FAQ
Is this actually free, or is that a trick?
The Continuous Migration core — why to migrate, the budget, the target architecture, and pg_auto_failover — is free, permanently, no card required. The hands-on pgloader mechanics, casting rules, and stored-procedure porting are the paid course.
Do I need a PostgreSQL background to use this?
No — this is written for developers and DBAs coming from MySQL. Where PostgreSQL behaves differently, that's the whole point of the FAQ section.
Does pgloader handle Oracle or MS SQL Server too?
Yes, MS SQL Server is a supported source today; Oracle is on pgloader's roadmap, not yet shipped. This site is scoped to MySQL specifically.
I run pgloader in production — should I be paying for something?
If pgloader is part of your production workflow, its maintenance is worth funding — see the Support pgloader page.
