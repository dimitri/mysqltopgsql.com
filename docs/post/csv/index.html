How to output MySQL query results in CSV format?

PostgreSQL COPY and psql output formats.

PostgreSQL implements the COPY protocol and command to output data formatted in CSV. The psql command line client also knows how to produce some other formats, such as XML, asciidoc, or latex.

The simplest way to have your query result in CSV is the following:

copy (
      select format('%s %s', drivers.forename, drivers.surname) as name,
             sum(points) as points
        from drivers
             join results using(driverid)
             join races using(raceid)
       where races.year = 2016
    group by drivers.driverid
    order by points desc
)
to stdout with csv header;

It is possible to change the delimiter of course:

copy (
      select format('%s %s', drivers.forename, drivers.surname) as name,
             sum(points) as points
        from drivers
             join results using(driverid)
             join races using(raceid)
       where races.year = 2016
    group by drivers.driverid
    order by points desc
)
to stdout with csv header delimiter E'\t';

Is this actually free, or is that a trick?
The Continuous Migration core — why to migrate, the budget, the target architecture, and pg_auto_failover — is free, permanently, no card required. The hands-on pgloader mechanics, casting rules, and stored-procedure porting are the paid course.
Do I need a PostgreSQL background to use this?
No — this is written for developers and DBAs coming from MySQL. Where PostgreSQL behaves differently, that's the whole point of the FAQ section.
Does pgloader handle Oracle or MS SQL Server too?
Yes, MS SQL Server is a supported source today; Oracle is on pgloader's roadmap, not yet shipped. This site is scoped to MySQL specifically.
