Module 04 · Standing up the monitor
$ pg_autoctl create monitor \
    --pgdata monitor \
    --auth trust --ssl-self-signed

$ pg_autoctl create postgres \
    --pgdata node1 \
    --monitor postgres://.../pg_auto_failover

The two commands that turn a Primary/Secondary pair into a self-healing cluster.

Module 06 · A real .load file
load database
  from mysql://root@unix:/tmp/mysql.sock/db
  into pgsql:///db

 CAST column base64.id to uuid
       drop typemod drop not null,
      column base64.data to jsonb
       using base64-decode;

Casting a base64-encoded id column straight to uuid, on the fly.
